# Personal-Finance
The Personal Finance Dashboard helps track income, expenses, and savings to provide a clear view of financial health. It Higlights key metrics, spending patterns, and category-wise expenses through interactive visuals. The dashboard enables better budgeting, financial planning, and data-driven decision-making. 

The dashboard reveals that a significant portion of income is spent on a few major categories, indicating potential areas for cost optimization. Monthly trend analysis shows fluctations in expenses, highlighting the importance of consistent budgeting. It also identifies periods of higher savings strategies, and smarter financial decision making.
